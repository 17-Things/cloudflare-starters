## When you add your own photo

1. Save it in this folder with the same file names, in WebP format, at the
   same widths (the number in each file name is its width in pixels).
2. Or use new names, and change the `src` and `srcset` lines in the HTML.
3. Change the `alt` text so it describes your photo in plain words.
4. Remove the row from this file, or add your own credit.
